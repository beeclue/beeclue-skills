# Evaluation Scenario: Enterprise AI & Developer Infrastructure (Aether Compute)

This evaluation tests `beeclue-next-theme` in generating an enterprise developer infrastructure platform with live telemetry, bento widgets, and strict dark mode precision.

---

## 1. Input Brief
- **Company**: Aether Compute
- **Category**: High-performance GPU cluster orchestration for autonomous AI agent training.
- **Audience**: VP of Infrastructure, AI Research Directors, ML Platform Engineers.
- **Conversion**: Request Enterprise POC & Cluster Access.
- **Required Sections**: Hero with live latency telemetry, Bento feature matrix, Architecture integration map, SOC 2 compliance strip, Enterprise FAQ.

---

## 2. Evaluation Criteria
1. **Zero AI Cliché Compliance**:
   - Zero emojis in any copy or button.
   - Zero decorative pill chips over headings.
   - Distinct slate/obsidian palette (no purple/indigo gradients).
2. **Apple Design Polish**:
   - Razor-thin 1.25px stroke luxury icons (`Cpu`, `Server`, `ShieldCheck`, `Terminal`).
   - Liquid frosted glass header with dynamic scroll blur.
   - Fluid typography with negative tracking on display headlines (`tracking-[-0.03em]`).
3. **Technical SEO & Structured Data**:
   - Complete Metadata API configuration.
   - `Organization` and `SoftwareApplication` JSON-LD schemas.
4. **Mandatory Branding**:
   - Beeclue Tech attribution link with UTM parameters in footer.
