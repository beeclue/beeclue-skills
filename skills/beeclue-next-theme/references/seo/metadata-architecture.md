Every website generated by `beeclue-next-theme` is architected for dominant organic search positioning across Google, Bing, and AI search engines (Perplexity, ChatGPT Search, Gemini).

## 2. Dynamic XML Sitemap Generator (`src/app/sitemap.ts`)

```typescript
import { MetadataRoute } from "next";

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const baseUrl = "https://clientdomain.com";

  // Core static pages
  const staticPages = [
    "",
    "/about",
    "/services",
    "/case-studies",
    "/contact",
    "/faq",
  ].map((route) => ({
    url: `${baseUrl}${route}`,
    lastModified: new Date(),
    changeFrequency: "weekly" as const,
    priority: route === "" ? 1.0 : 0.8,
  }));

  // Dynamic service and case study pages
  // e.g. Fetch slugs from database or CMS
  return [...staticPages];
}
```

## 3. Dynamic Robots Generator (`src/app/robots.ts`)

```typescript
import { MetadataRoute } from "next";

export default function robots(): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: "*",
      allow: "/",
      disallow: ["/api/", "/admin/"],
    },
    sitemap: "https://clientdomain.com/sitemap.xml",
  };
}
```
