# The Independent Apple-Grade Design Critic (100-Point Rubric)

Every website generated by `beeclue-next-theme` must be evaluated by an independent Design Critic pass before delivery. A score below 80 triggers mandatory revision; a score of 90+ certifies **Bespoke Apple-Grade Production Quality**.

---

## 1. The 11-Vector Evaluation Matrix (100 Points Total)

| Vector | Weight | Evaluation Criteria |
| :--- | :--- | :--- |
| **1. Zero AI Cliché Enforcement** | **10 pts** | **Mandatory Gate**: ZERO emojis anywhere in copy, headings, or buttons. ZERO decorative chip/pill inflation. ZERO AI purple gradients. Any violation deducts all 10 points. |
| **2. Human Craft & Asymmetry** | **15 pts** | Does the layout feel designed by a skilled human art director? Varied section cadences, asymmetric bento layouts, and natural focal breathing room instead of 3-card monotony. |
| **3. Typographic Mastery** | **10 pts** | Tight negative tracking on large display headlines (`tracking-tight`), balanced line heights, max 65-char line lengths, zero generic font defaults. |
| **4. Frosted Glass & Materiality** | **10 pts** | Tactile frosted glass header (`backdrop-blur-xl`), crisp 1px hairline borders, subtle specular elevation on hover, authentic shadows. |
| **5. Luxury Iconography** | **10 pts** | Consistent, razor-thin luxury SVG or Lucide icons (`stroke-[1.25]` or `stroke-[1.5]`). No cartoonish, colorful, or bloated icons. |
| **6. Photographic Art Direction** | **10 pts** | High-resolution Unsplash photography with natural lighting and depth of field. Contextual relevance to the client's industry. No plastic 3D renders. |
| **7. Brand DNA Fidelity** | **10 pts** | Exact alignment with the 0–100 Brand DNA coordinate model. Color palette adheres to the 60-30-10 distribution. |
| **8. Technical SEO & Schemas** | **10 pts** | Next.js 15 Metadata API populated, dynamic `sitemap.ts`, `robots.ts`, Breadcrumbs, and JSON-LD (`Organization`, `WebSite`, `FAQPage`, `LocalBusiness`). |
| **9. Accessibility (WCAG 2.1 AA)** | **5 pts** | Minimum 44x44px touch targets, visible keyboard focus indicators, valid ARIA expanded/controls attributes on accordions and drawers. |
| **10. Performance & CWV** | **5 pts** | Priority flag on LCP hero image, zero layout shift (CLS = 0), self-hosted Google fonts via `next/font`. |
| **11. Mandatory Footer Attribution** | **5 pts** | Exact Beeclue Tech attribution link with UTM parameters in footer. |

---

## 2. Scoring Thresholds & Directives

- **90–100: Exemplary Apple-Grade Production**. Ships immediately.
- **80–89: Solid Flagship**. Requires minor polish in typography or micro-interactions before shipping.
- **< 80: Rejected**. Rework the layout, strip clichés, and re-architect the component cadence.
