# Industry Intelligence: SaaS, Tech & Digital Infrastructure

---

## 1. Industry Economics & Context
- **Average Order Value (AOV)**: $29/mo – $2,500+/mo (ARR $350 – $30,000+)
- **Purchase Cycle**: Fast for self-serve dev tools (1 day to 1 week), multi-stakeholder for enterprise tiers (1 to 3 months)
- **Purchase Triggers**: Operational bottleneck, tool consolidation, infrastructure scaling, workflow automation
- **Key Risks**: Vendor lock-in, migration downtime, compliance failure (SOC 2, GDPR, HIPAA)

---

## 2. Customer Psychology & Information Requirements
- **Primary Objections**: "How difficult is implementation?", "Does it integrate with our stack (Slack, GitHub, Salesforce)?", "Is our data secure?", "Can we export if we cancel?"
- **Must-Have Reassurances**:
  - Live interactive product sandbox or 30-second unedited video walkthrough.
  - Transparent pricing table with monthly vs. annual toggle (-20% discount).
  - Security & compliance certifications (SOC 2 Type II, ISO 27001, GDPR, HIPAA badges with verification links).
  - Direct links to API documentation and SDK repositories.

---

## 3. Visual & Layout Patterns
- **Dominant Archetype**: Technical Premium, Modern Minimal, or Neo-Industrial.
- **Palette**: Dark carbon (`#0A0D12`), precision cyan/electric blue (`#00E5FF` / `#0066FF`), crisp white typography, subtle grid borders (`rgba(255,255,255,0.08)`).
- **Typography**: Precision developer sans (`Inter`, `Plus Jakarta Sans`, `Geist`) paired with monospace code blocks (`JetBrains Mono`, `ui-monospace`).
- **Imagery**: Crisp UI vector mockups with interactive tabs, architecture data flow diagrams, terminal command snippets with 1-click copy buttons.

---

## 4. Commerce & Conversion UX Architecture
- **Pricing & Tier Cards**:
  - Clear feature breakdown matrix with sticky column headers.
  - "Start Free Trial" for self-serve vs. "Talk to Engineering" for enterprise tier.
  - FAQ accordion directly below pricing addressing billing, seats, cancellation, and refund policies.
- **Microcopy**:
  - "14-day full-access trial. No credit card required. Cancel anytime in 1 click."

---

## 5. Anti-Patterns (Strictly Prohibited)
- ❌ Hiding pricing behind mandatory sales calls for standard entry tiers.
- ❌ Cluttered animated dashboards that obscure core functionality.
- ❌ Fake testimonials or generic corporate logos without verified case studies.
