# Online Store 2.0 (OS 2.0) Architecture & Core Principles

Shopify Online Store 2.0 revolutionized Shopify theme development by decoupling layouts into modular, reorderable JSON templates, universal sections, and app blocks. Every theme generated by Beeclue Tech is engineered from scratch on OS 2.0 principles.

## 2. JSON Templates (`templates/*.json`)

In OS 2.0, page layouts are declared as JSON files rather than static `.liquid` files. This allows store merchants to add, reorder, hide, and configure sections dynamically in the Shopify Theme Editor.

### Anatomy of `templates/index.json`:
```json
{
  "sections": {
    "hero": {
      "type": "hero-banner",
      "settings": {
        "heading": "Crafted for Generations",
        "subheading": "Bespoke stoneware, hand-thrown in Kyoto",
        "cta_label": "Explore Collection",
        "cta_link": "/collections/all"
      }
    },
    "trust_ribbon": {
      "type": "trust-marquee",
      "settings": {}
    },
    "featured": {
      "type": "featured-collection",
      "settings": {
        "title": "Signature Pieces",
        "collection": "frontpage",
        "products_to_show": 4
      }
    },
    "story": {
      "type": "image-with-text",
      "settings": {
        "title": "The Art of Restraint"
      }
    },
    "bento": {
      "type": "bento-grid",
      "settings": {}
    },
    "faq": {
      "type": "faq-accordion",
      "settings": {}
    }
  },
  "order": [
    "hero",
    "trust_ribbon",
    "featured",
    "story",
    "bento",
    "faq"
  ]
}
```

## 3. Section Groups

Section groups (`sections/header-group.json` and `sections/footer-group.json`) represent global areas that wrap around every template:
- Allows merchants to add announcement bars, utility banners, or popups without touching `layout/theme.liquid`.
- Rendered in `theme.liquid` via `{% sections 'header-group' %}` and `{% sections 'footer-group' %}`.

---

## 4. App Blocks & App Embeds

To maintain compatibility with modern Shopify apps (reviews, subscriptions, sizing charts, loyalty programs):
- Every section supporting third-party widgets must define `{% content_for 'blocks' %}` or specify `"type": "@app"` in the section schema blocks.
- `theme.liquid` must always include `{{ content_for_header }}` before `</head>` and `{{ content_for_footer }}` before `</body>`.

## 5. Section Rendering API

The Section Rendering API allows fetching pre-rendered HTML for any section dynamically by passing `?sections=section-id` in a query parameter.

When updating the cart drawer:
```javascript
fetch('/cart/add.js', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    items: [{ id: variantId, quantity: 1 }],
    sections: ['cart-drawer', 'cart-icon-bubble']
  })
})
.then(res => res.json())
.then(data => {
  // Update cart drawer HTML directly from server
  document.getElementById('cart-drawer-container').innerHTML = data.sections['cart-drawer'];
  // Open cart drawer
  document.querySelector('cart-drawer').open();
});
```
This guarantees that server-side Liquid logic (free shipping progress, tax notices, line item totals) stays perfectly synced without duplicating business logic in JavaScript.
