# beeclue-skills

A curated suite of agentic skills by **Beeclue Tech** for building high-converting, accessible, and high-performance digital products and storefronts.

## Available Skills

| Skill | Directory | Description |
| :--- | :--- | :--- |
| **[beeclue-woocommerce-theme](./skills/beeclue-woocommerce-theme)** | `skills/beeclue-woocommerce-theme` | Automates the creation of production-ready, superclass WooCommerce themes with multi-skill design orchestration (`ui-ux-pro-max`, `design-system`, `brand`, `agency-whimsy-injector`, `a11y-debugging`), 3-layer design tokens, dynamic AJAX cart drawer with free shipping progress bar, floating single-product sticky bar, visual swatches, and WCAG 2.1 AA compliance. |

## Usage

To use these skills with Claude Code or other AI agentic coding systems, install or symlink the target skill folder into your agent's skills directory (e.g. `~/.gemini/config/skills/` or `~/.claude/skills/`).

### Triggers for `beeclue-woocommerce-theme`
- `"create woocommerce theme"`
- `"superclass theme"`
- `"build wordpress store"`
- `"beeclue theme"`
- `"new client site"`
- `"new wordpress theme"`
